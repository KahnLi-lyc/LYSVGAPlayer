# Fixture attribution

`mutiMatte.svga`, `matteRect.svga`, `matteBitmap_1.x.svga`, and `rose_2.0.0.svga` are sample assets copied from
[SVGAPlayer 2.5.8](https://github.com/svga/SVGAPlayer-iOS), pinned to commit
`98cb1825cfbea8506e979d28d0a9269dcf12c20a`.

The upstream project and these sample assets are distributed under Apache
License 2.0. They are included solely as parser interoperability fixtures.

Files under `Snapshots/` are deterministic 128 x 128 sRGB renderer outputs
generated by LYSVGAPlayer from those fixtures and are used only for pixel
regression testing.

`unsafeTraversal.svga` and `unsafeSymlink.svga` are synthetic security test
archives created for LYSVGAPlayer and contain no upstream media.
